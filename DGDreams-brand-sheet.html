Usage

  • Clear space = height of the spark × 2 (≈27 units of 96). Nothing enters it.
  • Minimum size 16 px square avatar, 20 px bare mark; below that use the square tile, not the bare D.
  • Never stretch, outline, add a second hue to the spark, or put the mark inside a circle — the D already reads as a shape.
  • Type Archivo SemiCondensed ExtraBold for the wordmark (−1.4% tracking), IBM Plex Mono for data. Both already ship with the app.
  • Contrast the gradient needs a dark or paper background; on mid-greens use mark-on-accent (ink knock-out).
